# 桌面客户端

本页介绍跨平台桌面同步客户端（Windows / macOS / Linux）：获取与打包方式、首次运行向导、双向同步机制详解、冲突策略、排他锁与保存回传、回收站与历史版本入口、托盘常驻与开机自启、安全存储与常见操作示例。

> 客户端基于 **Electron 33 + electron-vite + Vue 3 + better-sqlite3 + chokidar**，将本地指定文件夹与云盘实时双向同步；同时内置部门网盘在线浏览（不占用本地同步目录）。

## 获取与安装

- **发布产物**：由仓库 `client/` 目录打包（见 [打包发布](./09-Architecture-Development.md#客户端打包发布)）：
  - Linux：`npm run package:linux` → AppImage
  - Windows：`npm run package:win` → 免安装便携版（portable exe）
  - macOS：`npm run package:mac` → zip（x64 + arm64；macOS 本机构建可改用 dmg）
- 产物输出到 `client/dist/`。
- **开发运行**：

```bash
cd client
npm install          # 内置 .npmrc，自动使用 npmmirror 镜像（含 Electron 与 better-sqlite3 二进制）
npm run dev          # electron-vite 开发模式
# 或构建后直接运行：
npx electron-vite build && ./node_modules/.bin/electron .
```

> better-sqlite3 为原生模块，npm 按 Electron ABI 自动编译；若提示 ABI 不匹配，执行 `npx electron-rebuild -f -w better-sqlite3`。
> Linux 无 root 环境：若无法为 `chrome-sandbox` 设置 SUID，开发时追加 `--no-sandbox --disable-gpu-sandbox`；正式安装包（deb/AppImage）自动配置沙箱。

## 首次运行向导

四步完成配置，任一步含连通性/合法性校验：

| 步骤 | 内容 |
|------|------|
| 1. 服务器地址 | 填 Web 访问地址（如 `http://<服务器IP>:8080`），**无需带 `/api`**；自动测试连通性 |
| 2. 账号密码 | 登录校验，获取 JWT |
| 3. 本地同步路径 | 选择本地文件夹（云端文件将同步到此处） |
| 4. 开机自启 | 可选勾选 |

配置残缺（已配置但缺少同步路径）时会**强制回到向导**，避免后续请求 "Invalid URL"。

完成向导后执行**首次全量同步**：自动将云端全部文件（含多级目录）下载到本地同步文件夹。

## 同步机制详解

### 本地 → 云端（实时监听）

- chokidar 监听本地同步文件夹的增/删/改/重命名/移动；
- **重命名与移动智能配对**：识别为改名/移动而非「删除+重传」，不产生冗余流量；
- 上传统一走「**秒传 → 分片续传 → 整文件**」三级通道：>20MB 自动 5MB 分片（并发 3、单片重试 3 次），中断后仅补传缺失分片。

### 云端 → 本地（定时轮询）

- 默认 **60 秒**轮询一次服务端变更（可在设置中调整 10–600 秒），拉取并同步到本地；
- 本地镜像库（better-sqlite3）保存远端树快照、本地指纹与同步日志，用于 diff 与断点判断。

### 下载断点续传

- 下载支持 HTTP Range（206），中断后从 `.zhy.part` 断点追加，`.zhy.meta` 防止不同文件临时文件串用；
- 完成后校验大小与 MD5，校验通过才替换正式文件。

### 同步历史

主界面三标签页：**全部记录 / 已同步 / 失败**，实时显示每个文件的下载、上传、删除、改名、移动记录及失败原因。

## 冲突策略

同一文件本地与云端同时变更时按设置处理：

| 策略 | 行为 |
|------|------|
| `keep-both`（默认，保留两者） | 自动生成「服务器冲突」副本，本地与云端版本都保留 |
| `last-write-wins`（最后修改者胜出） | 以较新修改时间的一方覆盖另一方 |

## 排他锁与保存回传

针对**部门网盘**文件（个人同步盘不涉及）：

1. **打开即抢锁**：双击部门文件 → 客户端调用 `POST /api/file/lock/acquire` 抢排他锁；抢锁失败则以**只读**方式打开并提示「文件正被 XX 编辑」，只读文件本地置只读位且**绝不回传**。
2. **临时目录编辑**：文件下载到临时缓存目录，调用本机默认程序打开；客户端心跳每 **30 秒**续约（锁 TTL 2 分钟）。
3. **保存自动回传**：编辑保存后自动回传服务端（读写权限），回传走配额与指纹校验；**回传成功后立即释放锁**；另存到其他位置不回传。
4. **关闭探测（v1.3.1）**：客户端心跳周期内探测缓存文件是否仍被编辑器独占，连续 2 轮（约 60~90s）未占用即自动释放锁并停止续约，修复编辑锁残留问题；轻量编辑器（不持续持有句柄）误判提前释放由「保存回传前重新抢锁」兜底。
5. **异常兜底**：崩溃/断网由 TTL 过期 + 服务端每 5 分钟清理任务回收；他人持锁时覆盖/改名/移动/删除由服务端拒绝（业务码 `3501`）。

临时缓存目录退出客户端自动清理，超期缓存自动删除。

## 回收站与历史版本入口

> v1.3.1 新增。

| 入口 | 能力 |
|------|------|
| 首页 · 回收站 | 查看 / 还原 / 彻底删除 / 清空**个人回收站**；显示删除人与剩余保留天数；个人盘变更后自动触发一次同步对齐本地文件夹 |
| 部门网盘 · 回收站 | 对所选部门执行相同操作（沿用部门读写权限） |
| 部门网盘 · 文件行「版本」 | 查看版本列表（版本号 / 大小 / 修改人 / 保存时间）、下载任意历史版本到本地、一键恢复（当前内容自动另存为新版本，可来回切换） |

## 托盘常驻与开机自启

- 关闭主界面后**驻留系统托盘**继续同步；
- 托盘右键菜单：打开主界面、打开同步文件夹、立即同步、设置开机自启、退出；
- 开机自启基于 `auto-launch` 实现，可在向导第 4 步或设置页开关。

## 安全存储

- **JWT 加密保存**：通过系统密钥环加密（Electron `safeStorage` / macOS Keychain / Windows DPAPI），不以明文落盘；
- **401 自动刷新**：access token 过期自动用 refresh token 续期（refresh 有效期默认 30 天），无感恢复登录态；
- 设置持久化在 electron-store（`settings.json`），仅保存服务器地址、账号、同步路径、轮询间隔、冲突策略等非敏感项。

## 常见操作示例

| 场景 | 操作 |
|------|------|
| 首次使用 | 运行客户端 → 四步向导 → 等待全量首同步完成 |
| 日常办公 | 把文件放进本地同步文件夹即自动上云；云端变更约 60s 内落本地 |
| 大文件上传 | >20MB 自动分片；中断后重新拖入同一文件仅补传缺失分片 |
| 断网恢复 | 上传/下载自动从断点续传，完成后 MD5 校验 |
| 团队协作编辑 | 从客户端「部门网盘」双击打开文件编辑保存；他人持锁时只读打开，等锁释放后再编辑 |
| 误删恢复 | 打开回收站 → 还原到原位置（个人盘还原后自动同步到本地） |
| 版本回滚 | 部门文件「版本」入口 → 选择历史版本 → 一键恢复 |

## 客户端设置项

设置页（SettingsView）可配置项与默认值（存储于 electron-store `settings`）：

| 设置项 | 键 | 默认值 | 范围/可选值 |
|--------|----|--------|-------------|
| 服务器地址 | `serverUrl` | 空（向导填写，**只读**展示） | 如 `http://IP:8080` |
| 账号 | `username` | 空（向导填写，**只读**展示） | — |
| 同步文件夹 | `syncPath` | 空 | 本地目录选择器 |
| 轮询间隔 | `pollInterval` | `60` 秒 | 10–600，步进 10 |
| 冲突策略 | `conflictStrategy` | `keep-both` | `keep-both`（保留两者）/ `last-write-wins`（最后修改者胜出） |
| 开机自启 | `autoStart` | `false` | 开关 |
| 是否完成配置 | `configured` | `false` | 内部状态，重置后回到向导 |
