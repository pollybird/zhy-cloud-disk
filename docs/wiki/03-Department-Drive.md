# 部门网盘使用

本页介绍多级部门共享网盘（v1.1.0 起提供的可选功能）：部门树管理、成员与权限模型、部门管理员委派、文件夹级授权与到期、部门文件操作、排他编辑锁、部门回收站与历史版本、功能开关与关闭行为、删除保护。

> 部门网盘与个人网盘**物理目录、配额、权限完全隔离**；安装时未开启则所有部门功能不存在，个人功能与 v1.0.0 完全一致。

## 开启方式与功能开关

- **安装时开启**：Web 安装向导勾选「开启部门共享网盘」；Docker 静默安装用环境变量 `ZHY_DEPARTMENT_DRIVE=true`（compose 部署默认 `true`，见 [安装部署](./01-Installation.md)）。
- 开关持久化在 `system_setting` 表（键 `department_drive_enabled`），服务**启动时读取一次**并注册部门相关蓝图；关闭时部门相关接口由应用级守卫统一拒绝。
- **关闭时的接口行为**：`/api/department/*`、`/api/permission/*`、`/api/log/*` 返回 HTTP 403、业务码 `4030`「部门网盘功能未开启」；个人网盘接口与 `/api/system/feature-flags`（需登录）不受影响。
- 前端菜单「部门网盘」「部门管理」等仅在该开关开启时显示；变更开关后需重启服务生效。

## 部门树管理

超管在「部门管理」页（`/departments`）维护无限级部门树：

| 操作 | 接口 | 规则 |
|------|------|------|
| 新增部门 | `POST /api/department` | 名称非空、长度受限（`3303`）；同级不重名（`3304`）；仅超管可创建根部门（`3302`） |
| 重命名 / 排序 / 配额 | `PUT /api/department/<id>` | 同级排序 `sort_order`；部门独立存储配额 `storage_quota`，`0` 表示不限额；仅超管可调配额（`3305`），不能低于当前已用（`3306`） |
| 迁移 | `POST /api/department/<id>/move` | 仅超管（`3302`）；不能移动到自身或其子部门下（`3305`） |
| 删除 | `DELETE /api/department/<id>` | 删除保护见 [下文](#删除保护)；删除空部门会一并清理其成员、管理员与授权关联，审计日志不受影响 |
| 查询 | `GET /api/department/tree` | 按当前用户权限过滤可见范围；超管场景无 N+1（实测 7 层 127 部门树约 4ms） |

性能与缓存：部门管理员权限 TTL 60 秒、文件权限 TTL 30 秒，授权变更主动失效。

## 成员与权限模型

部门成员在「部门成员」页（`/department-members`）维护。成员默认**只读**；可显式授予三级权限：

### 权限矩阵

| 权限值 | 含义 | 浏览/下载 | 上传/新建 | 改名/移动/删除 | 排他编辑锁 |
|--------|------|-----------|-----------|----------------|------------|
| `read_only` | 只读（成员默认） | ✅ | ❌ | ❌ | ❌ |
| `read_write` | 读写 | ✅ | ✅ | ✅ | ✅ 可抢锁 |
| `denied` | 拒绝 | ❌ | ❌ | ❌ | ❌ |

优先级：**拒绝 > 显式授权 > 成员默认只读**。支持文件夹级授权与到期时间（见下）。

| 操作 | 接口 | 说明 |
|------|------|------|
| 添加成员 | `POST /api/department/<id>/members` | 可带职位；重复添加返回 `3308`；禁用用户不能加入（`3307`） |
| 更新职位 | `PUT /api/department/<id>/members/<user_id>` | 仅职位字段 |
| 移除成员 | `DELETE /api/department/<id>/members/<user_id>` | 不是成员返回 `3309` |
| 候选用户 | `GET /api/department/<id>/candidate-users` | 排除已是成员的用户，最多 20 条，支持关键词 |
| 授予权限 | `POST /api/permission/grant` | 见下节 |
| 撤销权限 | `DELETE /api/permission/<perm_id>` | 权限记录不存在 `3408` |
| 查询部门权限 | `GET /api/permission/department/<dept_id>` | 授权明细列表 |
| 我的权限 | `GET /api/permission/my` / `GET /api/permission/my-admin-depts` | 前端权限感知 |

## 部门管理员委派

| 项目 | 规则 |
|------|------|
| 委派 | `POST /api/permission/admin`：参数 `department_id`、`user_id`、`scope`（`self` 仅本部门 / `self_and_sub` 本部门及子部门，其他值 `3401`） |
| 撤销 | `DELETE /api/permission/admin/<dept_id>/<user_id>`；不是管理员返回 `3404` |
| 列表 | `GET /api/permission/admins/<dept_id>` |
| 权限边界 | 仅超管可委派/撤销**根部门**管理员（`3402`）；部门管理员只能在本部门管辖范围内委派下级 |
| 能力 | 部门管理员可管理本部门（按 scope 含子部门）的成员、授权、部门文件与回收站、查看部门审计日志；不能调整部门配额（仅超管） |

## 文件夹级授权与到期

`POST /api/permission/grant` 支持：

| 参数 | 说明 |
|------|------|
| `user_id` / `department_id` | 授权对象与所属部门 |
| `folder_id` | 可选；指定部门内某文件夹，则该授权只对该文件夹子树生效 |
| `permission` | `read_only` / `read_write` / `denied`（其他值 `3405`） |
| `expire_time` | 可选到期时间，过期后授权自动失效 |

校验：目标文件夹必须存在且为文件夹（`3406`）、必须属于该部门（`3407`）。

## 部门文件操作

「部门网盘」页（`/department-files`）按权限显示可见部门树与文件列表：

- **上传**：按钮选择或拖拽（含文件夹上传）；走 MD5 秒传预检与配额原子扣减；无写权限返回 `4032`「无权上传到该部门」。
- **管理**：文件夹递归创建、改名、移动（个人/部门之间禁止互移 `3109`）、下载、删除；操作均记入审计日志。
- **列表增强字段**：`GET /api/file/list?department_id=` 每项额外返回 `locked`、`locked_by_me`、`lock_user_name`（排他锁状态）。
- **桌面客户端**：部门网盘在线浏览（不占用本地同步目录）、双击下载到临时目录用本机程序打开、保存自动回传（详见 [桌面客户端](./04-Desktop-Client.md)）。

## 排他编辑锁

> v1.2.0 引入，防止多人同时编辑覆盖冲突。仅部门文件可加锁（个人文件返回 `3503`）。

### 生命周期

| 阶段 | 行为 |
|------|------|
| 抢锁 | 读写用户在桌面客户端**打开**部门文件时自动 `POST /api/file/lock/acquire`；幂等，持有者重复获取即续约 |
| 他人视角 | 其他读写用户该文件降级为**只读**（文件图标红色锁角标，悬停显示持有者「文件正被 XX 编辑」），只读文件本地置只读位且绝不回传 |
| 心跳 | 编辑期间客户端每 **30 秒** `POST /api/file/lock/heartbeat` 续约，锁 TTL **2 分钟** |
| 正常释放 | **保存回传成功后立即释放**；再次编辑保存时自动重新抢锁（v1.3.1 兜底轻量编辑器误判提前释放的场景） |
| 崩溃回收 | 客户端崩溃/断网由 TTL 自动过期 + 每 **5 分钟**清理任务物理删除过期行；v1.3.1 客户端心跳周期内探测编辑器关闭，连续 2 轮（约 60~90s）未占用自动释放，避免锁残留 |
| 强制释放 | 超管/部门管理员可 `POST /api/file/lock/release` 带 `force: true` 释放他人锁（`4032` 无权） |

### 服务端硬拦截

锁被他人持有时，**覆盖保存 / 重命名 / 移动 / 删除**（含包含被锁文件的文件夹）一律返回 HTTP 409、业务码 `3501`，data 中含持有者 `user_id`/`user_name`；**下载、在线预览等读操作不受影响**。释放相关错误码：`3502`（文件未被锁定 / 只有持有者可释放）。

### 锁状态查询

`GET /api/file/lock/status?id=` 返回当前锁信息（是否被锁、持有者、是否自己持有）。

## 部门回收站与历史版本

- 部门盘有**独立回收站**：`GET /api/file/trash?scope=department&department_id=`；还原/彻底删除/清空沿用部门读写权限；显示删除人与剩余保留天数。
- 部门文件**覆盖上传自动留历史版本**，文件行「历史版本」入口可查看（版本号/大小/修改人/保存时间）、下载任意历史版本、一键恢复；Web 与桌面客户端（v1.3.1）均支持。
- 策略（保留天数、版本数）与个人盘共用同一组系统设置，见 [管理后台 · 系统设置](./05-Admin-Console.md#系统设置)。

## 删除保护

- 部门（含任意子孙部门）下仍存在**正常文件或文件夹**时，删除请求返回 HTTP 409、业务码 `3310`，请先迁移或清空文件后再删除。
- 删除空部门会一并清理其成员、管理员与授权关联；审计日志不受影响。

## 部门配额与文件视图细节

- **部门配额**：独立于成员个人配额，部门级 `storage_quota`（`0` = 不限额）；上传走配额原子扣减，超额返回 `3106`（HTTP 413）；仅超管可调整，不能低于当前已用。
- **文件分类图标**：办公文档 / 图片 / 视频 / 音频 / 压缩包等 8 类彩色图标，与个人盘共用分类规则。
- **列表锁字段**：`GET /api/file/list?department_id=` 返回的每个文件项带 `locked`（是否被锁）、`locked_by_me`（是否自己持有）、`lock_user_name`（持有者名），前端据此渲染锁角标与只读态。
- **权限缓存**：部门管理员权限 TTL 60s、文件权限 TTL 30s；授权/撤销后主动失效，通常即时生效，极端情况 60s 内生效。

## 部门盘常见错误对照

| 提示 | 业务码 | 处理 |
|------|--------|------|
| 部门网盘功能未开启 | `4030`（HTTP 403） | 安装时开启该功能（见 [FAQ · Q15](./10-FAQ.md#q15部门网盘开关在哪改)） |
| 部门（含子部门）下仍有文件，禁止删除 | `3310`（HTTP 409） | 先迁移/清空文件再删部门 |
| 无权上传到该部门 / 无权访问该部门文件 | `4032` | 联系部门管理员授予 `read_write` |
| 文件正被「XX」编辑 | `3501`（HTTP 409） | 等待锁释放（TTL 2 分钟）或由管理员强制释放 |
| 同级已存在同名部门 | `3304`（HTTP 409） | 换名后再建 |
| 不能移动到自身或其子部门下 | `3305`（HTTP 409） | 调整目标父部门 |
| scope 必须为 self 或 self_and_sub | `3401` | 使用合法的管理范围值 |

## 审计日志

- 记录部门内上传、删除、移动、授权等关键操作。
- `GET /api/log/global`（仅超管）：全局日志，支持 `action`、`department_id`、`user_id` 筛选。
- `GET /api/log/department/<dept_id>`（需部门管理权限）：部门及子部门日志，支持 `action`、`user_id` 筛选。
- 分页参数：`page`（默认 1）、`size`（默认 20，最大 100）。
