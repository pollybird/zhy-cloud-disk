## 调用约定

| 项目 | 说明 |
|------|------|
| 响应包装 | 统一 `{ "code": ..., "msg": "...", "data": ... }`；JSON 与 HTTP 状态码一起返回 |
| 成功约定 | `code=0` 且 HTTP 200；`msg` 默认 `ok`，业务接口可带自定义成功提示 |
| 失败约定 | `code≠0` 为业务码，HTTP 状态码 4xx/5xx；`msg` 为可直接展示给用户的中文提示 |
| 两码独立 | HTTP 状态与业务码相互独立：HTTP 表达传输层语义（401 未认证 / 403 无权限 / 404 不存在 / 409 冲突 / 413 超限 / 429 限流 / 500 服务器错误），`code` 表达精确业务原因 |
| 默认 HTTP | 业务抛错未显式指定状态时默认 **HTTP 400**；下表「HTTP」列仅标注非 400 取值，`400/404` 之类的斜杠表示同一码在不同场景下状态不同 |
| data 附加信息 | 多数错误 `data=null`；例外：`3501` 锁冲突时 `data={user_id, user_name}`（锁持有者），可用于前端展示「谁正在编辑」 |
| 动态兜底 | 未被专门处理的 HTTP 异常按 `code = HTTP状态 × 10` 生成业务码（如 429→4290、429 之外的限流、503→5030），见 [其他与兜底规则](#其他与兜底规则) |

> 排查建议：前端/客户端遇到未知 `code` 时，按 HTTP 状态兜底处理（401 去登录、403 提示无权限、4xx 提示 `msg`、5xx 提示稍后重试），并以本页速查表核对是否已收录。

## 认证与账号

覆盖登录、注册、JWT 会话、个人改密与管理员用户管理。来源：`utils/errors.py`（JWT 回调与全局处理）、`utils/decorators.py`、`services/auth_service.py`、`services/user_service.py`、`utils/validators.py`、`api/auth.py`、`api/plugin.py`。

| 业务码 | HTTP | 含义 | 典型触发场景 | 处理建议 |
|--------|------|------|--------------|----------|
| 0 | 200 | 成功 | 所有成功响应 | 按 `data` 继续业务流程 |
| 4010 | 401 | 请先登录 | 请求未携带 `Authorization: Bearer`；插件流接口匿名且无分享令牌 | 跳转/弹出登录；客户端引导重新连接 |
| 4011 | 401 | 登录已过期，请重新登录 | access token 过期 | 用 `refresh_token` 调 `POST /api/auth/refresh` 静默换新；刷新失败再转登录页 |
| 4012 | 401 | 无效的登录凭证 | token 被篡改、格式错误或签名不匹配（如服务端换了 `SECRET_KEY`） | 清除本地保存的凭证后重新登录 |
| 4013 | 401 | 登录状态已失效，请重新登录 | token 已被吊销（登出后复用旧 token） | 重新登录；客户端应丢弃旧 token |
| 4014 | 401 | 用户不存在或账号不可用 | 登录时账号不存在或被删；请求过程中用户被管理员删除 | 提示「账号不可用」；退出到登录页，勿自动重试 |
| 4030 | 403 | 需要管理员权限；或「部门网盘功能未开启」 | 普通用户访问 `/api/admin/*` 等超管接口；部门网盘未开启时访问 `/api/department/*`、`/api/permission/*` | 前端按角色隐藏入口；部门功能开关可经 `GET /api/system/feature-flags` 预判，见 [部门网盘 · 开启方式](./03-Department-Drive.md#开启方式与功能开关) |
| 4031 | 403 | 账号已被禁用，请联系管理员 | 登录时 `status=disabled`；请求过程中账号被禁用 | 明确提示账号被禁用；不要反复重试 |
| 4032 | 403 | 无权访问该资源/操作 | 访问/移动/覆盖他人文件、对部门文件无读写权限却尝试加锁或上传、非部门管理员操作部门回收站、恢复他人文件的版本等 | 引导申请权限；部门场景先对照 [权限矩阵](./03-Department-Drive.md#权限矩阵) 检查 `read_only/read_write/denied` |
| 4040 | 404 | 资源不存在 | URL 路径写错（全局 404 兜底） | 检查路径拼写与 API 版本 |
| 4050 | 405 | 请求方法不被允许 | GET/POST/PUT/DELETE 用错 | 改用端点表标注的方法 |
| 4130 | 413 | 上传文件超过大小限制 | 请求体超过 `MAX_UPLOAD_SIZE`（默认 2GiB，`ZHY_MAX_UPLOAD_SIZE` 可调） | 上传前本地预检文件大小并提示上限；管理员可调整，见 [配置参考](./08-Configuration.md#密钥与业务参数运行期读取) |
| 5000 | 500 | 服务器内部错误 | 未处理异常（全局兜底） | 提示稍后重试；携带时间点反馈给管理员查日志 |
| 1001 | 400 | 用户名需为 3-32 位中英文、数字、下划线或连字符 | 注册、管理员创建用户 | 前端按同一正则预校验 |
| 1002 | 400 | 邮箱格式不正确 | 注册 | 前端邮箱格式校验 |
| 1003 | 400 | 密码长度需为 8-64 位 | 注册、创建用户、改密 | 前端长度校验 |
| 1004 | 400 | 密码须同时包含字母和数字 | 注册、改密 | 提示密码规则 |
| 1100 | 403 | 系统当前未开放注册 | `allow_register=false` 时调注册接口 | 引导联系管理员开设账号 |
| 1101 | 409 | 用户名或邮箱已被注册/已存在 | 注册重名；管理员创建用户重名 | 提示更换用户名或邮箱 |
| 1102 | 400 | 请输入用户名和密码 | 登录表单为空 | 前端必填校验 |
| 1103 | 401 | 用户名或密码错误 | 登录凭证不匹配 | 提示重新输入；服务端刻意不区分「用户不存在/密码错」 |
| 1201 | 400 | 原密码不正确 | 修改本人密码 | 提示重输原密码 |
| 1202 | 400 | 新密码不能与原密码相同 | 修改本人密码 | 提示设置不同的新密码 |
| 1203 | 400 | 存储配额必须为正整数字节 | 管理员设置/修改用户配额 | 传正整数字节数（如 `10737418240`），前端做单位换算 |
| 1204 | 404 | 用户不存在 | 管理员操作的目标用户已被删除 | 刷新用户列表后再操作 |
| 1205 | 400 | 新配额不能小于该用户已使用空间 | 缩减配额低于已用量 | 提示先清理文件或输入更大配额 |
| 1206 | 400 | 非法的账号状态 | `status` 传值不在启用/禁用枚举内 | 只传后端约定的枚举值 |
| 1209 | 400 | 角色必须为 admin 或 user | 创建/修改用户角色 | 枚举校验 |
| 1210 | 400 | 不能修改自己的角色/启用状态 | 管理员在用户管理中改自己 | 提示由其他管理员操作 |
| 1211 | 400 | 至少需要保留一个启用状态的管理员 | 停用/降级最后一个可用管理员 | 提示先启用其他管理员账号 |
| 1213 | 400 | 请通过个人中心修改自己的密码 | 管理员用户接口修改本人密码 | 前端引导跳转个人中心改密（`PUT /api/user/pwd`） |

## 安装与初始化

| 业务码 | HTTP | 含义 | 典型触发场景 | 处理建议 |
|--------|------|------|--------------|----------|
| 4001 | 503 | 系统尚未安装，请先完成安装向导 | 未安装时访问任意 `/api` 请求（`/api/ping` 与 `/api/setup/*` 除外） | 前端检测到 4001 直接重定向安装向导；客户端提示「服务未初始化」 |
| 2001 | 400 | 不支持的数据库类型 | 安装时 `database_type` 不是 mysql/sqlite | 使用受支持类型；数据库能力见 [备份与恢复 · 数据库支持矩阵](./06-Backup-Restore.md#数据库支持矩阵) |
| 2002 | 400 | SQLite 文件名不合法 | SQLite 文件名含路径分隔等非法内容 | 改为纯文件名 |
| 2003 | 400 | 请完整填写数据库主机、库名和账号 | 安装表单缺项 | 补全后重试 |
| 2004 | 400 | 数据库端口不合法 | 端口越界 | 传 1-65535 |
| 2005 | 400 | 无法识别的数据库连接串 | 直连 DSN（`database_uri`）前缀不被识别 | 核对 DSN 格式（如 `mysql+pymysql://...`） |
| 2006 | 400 | 数据库驱动缺失 | 未安装 pymysql 等驱动 | 安装对应驱动后重试 |
| 2007 | 400 | 数据库连接或写权限校验失败 | 主机/账号/密码错误、库不存在或不可写 | 核对连接信息；先调 `POST /api/setup/test-db` 预检 |
| 2008 | 400 | 存储目录不可写 | `storage_dir` 权限不足或不存在 | 修正目录权限（Docker 部署检查卷挂载） |
| 2009 | 400 | 目标数据库已存在用户数据，拒绝覆盖安装 | 重装到非空库 | 换空库，或确认是重装场景后先清库（参见 [备份与恢复](./06-Backup-Restore.md)） |
| 2010 | 400 | 安装配置写入失败 | 配置文件不可写 | 检查 instance 目录权限后重试 |
| 2020 | 403 | 系统已安装，安装向导已锁定 | 已安装后再调用 `/api/setup/install` 等向导接口 | 无需处理；升级按 [安装部署 · 升级流程](./01-Installation.md#升级流程) 走 |

## 个人文件与上传下载

覆盖存储层与文件基础操作（列表、新建、重命名、移动、删除、下载、传统整文件上传）。来源：`services/storage_service.py`、`services/file_service.py`、`api/file.py`。机制细节见 [个人网盘 · 上传机制](./02-Personal-Drive.md#上传机制秒传--分片--断点续传)。

| 业务码 | HTTP | 含义 | 典型触发场景 | 处理建议 |
|--------|------|------|--------------|----------|
| 3001 | 400 | 非法的存储路径 | 服务端存储路径安全校验未通过（正常调用不应出现） | 视为服务端异常，重试或反馈管理员 |
| 3002 | 400 | 文件名不合法 | 存储层文件名清洗失败（含路径分隔符等） | 重命名后再操作 |
| 3003 | 400 | 文件/分片保存失败 | 磁盘 IO 异常、目录不可写 | 检查服务器磁盘与挂载后重试 |
| 3004 | 400 | 文件路径缺失 | 下载时文件物理路径为空 | 该文件不可下载，重新上传 |
| 3005 | 400 | 非法的文件访问路径 | 下载路径越界（安全拦截） | 视为服务端异常，反馈管理员 |
| 3006 | 400 | 非法的文件指纹 | 传入 hash 不是合法的十六进制指纹 | 用标准 MD5（32 位）/SHA-256（64 位）十六进制小写串 |
| 3101 | 404 | 文件/文件夹不存在 | id 错误、文件已被删除或已进回收站 | 刷新列表后再操作 |
| 3102 | 400 | 目标不是文件夹 | 移动/进入目标实际是文件 | 改选文件夹 |
| 3103 | 409 | 同级目录下已存在同名文件或文件夹 | 新建、重命名、移动撞名 | 提示改名；或走覆盖流程（上传接口传 `overwrite_id`） |
| 3104 | 400 | 文件名过长/不合法 | 文件名超长或含非法字符 | 前端预校验文件名 |
| 3105 | 400 | 禁止上传/保存该后缀类型 | 后缀命中禁传列表（上传、新建、插件保存均会拦截） | 明确提示「.xxx 类型被禁止」；管理员可改设置，见 [个人网盘 · 文件类型限制](./02-Personal-Drive.md#文件类型限制) |
| 3106 | 413 | 存储空间不足，上传/保存被拒绝 | 用户配额或部门配额不足（含插件保存） | 提示清理空间或申请扩容；秒传命中同样占配额，解释见 [FAQ Q11](./10-FAQ.md#q11秒传是别人传过我就不用传了那我的空间还扣吗) |
| 3107 | 400 | 同名文件夹已存在 / 同名文件过多 | 新建文件夹撞名；覆盖处理时同名冲突过多 | 改名后重试 |
| 3108 | 400 | 不能覆盖文件夹 / 不能移动到自身或其子文件夹内 | 把文件夹移动到自己的子孙目录 | 改选其他目标目录 |
| 3109 | 409 | 不能在个人空间与部门网盘之间移动文件 | 跨域移动（物理存储与配额归属不同） | 提示不支持跨域移动，用下载后重新上传中转 |
| 3201 | 400 | 未选择上传文件 / 缺少分片数据 | 整文件上传缺 `files[]`；分片上传缺 `chunk` | 客户端补全 multipart 字段后重试 |
| 3202 | 400/413 | 缺少文件名或文件 id / 文件大小非法 / 超过最大允许大小 | 参数缺失；`file_size` 非法；超过 `MAX_UPLOAD_SIZE` | 补参重试；超限场景同 [4130](#认证与账号)，本地预检大小 |
| 3203 | 400 | 文件夹暂不支持打包下载 | 对文件夹调下载接口 | 提示逐个下载文件夹内文件 |
| 3204 | 410 | 物理文件已丢失 | blob 物理块缺失（磁盘故障/被清理），下载、分享下载、插件读取均可能触发 | 提示文件已损坏，删除后重新上传；管理员检查存储卷 |

## 秒传与分片

覆盖跨用户秒传、分片上传会话、分片校验与合并。来源：`services/file_service.py`、`services/blob_service.py`、`services/storage_service.py`、`api/file.py`。会话 24h 有效，过期清理任务见 [配置参考 · 定时任务](./08-Configuration.md#定时任务清单)。

| 业务码 | HTTP | 含义 | 典型触发场景 | 处理建议 |
|--------|------|------|--------------|----------|
| 3205 | 400 | 文件指纹校验失败，上传可能损坏 | 整文件上传后 MD5 不符；秒传指纹与大小不匹配；分片合并后总指纹不符 | 自动重传一次；客户端在上传前完成本地 MD5 计算可避免 |
| 3206 | 400 | 缺少合法的文件指纹 | 调 `/api/file/instant`、`/api/file/chunk/init` 时未带 `file_hash` | 先算好 MD5 再调用；秒传/分片流程 hash 必填 |
| 3207 | 400/404 | 上传会话不存在/已结束/已过期，或缺 upload_id | `upload_id` 缺失或非法（400）；会话被 `abort` 或超 24h 被清理后继续上传/合并（404 或 400） | 调 `POST /api/file/chunk/init` 重新初始化（同内容同位置会复用有效会话），或从头重传 |
| 3208 | 400 | 分片序号缺失/非法/大小不符；分片大小越界 | `index` 缺失、越界；分片实际大小与预期不符；`chunk_size` 不在 1MB~25MB 允许范围 | 以 `chunk/init` 返回的 `chunk_size`/`total_chunks` 为准重传对应分片 |
| 3209 | 400 | 分片指纹校验失败 | 单个分片传输中损坏 | 仅重传该分片（官方客户端单片自动重试 3 次） |
| 3210 | 400 | 分片不完整/总大小不一致/缺失，无法合并 | 有分片序号未上传完就调 `chunk/complete` | 先调 `GET /api/file/chunk/status` 找出缺失序号补传，再 complete |
| 3211 | 400 | 文件物理块缺失，请重新上传 / 去重注册失败 | 秒传命中但物理块已被回收；秒传注册并发冲突 | 降级为普通分片上传重试 |

## 部门排他锁

覆盖部门文件编辑互斥锁的获取、心跳、释放与状态查询。来源：`services/file_lock_service.py`。TTL 2 分钟 + 30s 心跳，详见 [部门网盘 · 排他编辑锁](./03-Department-Drive.md#排他编辑锁) 与 [桌面客户端 · 排他锁与保存回传](./04-Desktop-Client.md#排他锁与保存回传)。

| 业务码 | HTTP | 含义 | 典型触发场景 | 处理建议 |
|--------|------|------|--------------|----------|
| 3501 | 409 | 文件正被他人编辑（锁冲突） | `lock/acquire` 抢锁冲突；重命名/覆盖上传等写操作遇有效锁；`data` 携带 `{user_id, user_name}` | 提示「××正在编辑，请稍后再试」；可只读打开，或等 TTL（2 分钟无心跳）自动过期后重试；急用可请管理员 `force` 释放 |

| 3503 | 400 | 个人文件不支持编辑锁 | 对个人空间文件调用锁接口 | 仅部门文件支持排他锁，前端按 `department_id` 判断显隐 |

## 备份恢复
