## 文件与文件夹管理

Web 端「文件」页（`/files`）提供资源管理器式操作：

| 操作 | 说明 |
|------|------|
| 上传 | 按钮选择或拖拽；多文件；同名冲突时可选覆盖（覆盖自动进入历史版本） |
| 新建文件夹 | 支持多级嵌套；同级同名文件夹会被拒绝（业务码 `3107`） |
| 重命名 / 移动 | 移动不能进入自身或其子文件夹（`3108`）；个人与部门文件之间禁止互移（`3109`） |
| 下载 | 单文件下载（文件夹暂不支持打包下载，`3203`） |
| 删除 | 默认进入回收站（系统关闭回收站开关时为硬删除） |
| 分类检索 | 按图片 / 视频 / 文档 / 音频 / 压缩包等 8 类彩色图标分类，支持关键词搜索 |
| 列表分页 | `GET /api/file/list` 默认 50 条/页，最大 200 条/页 |

文件预览由插件系统提供（内置图片 / 视频 / 文档预览），详见 [管理后台 · 插件管理](./05-Admin-Console.md#插件管理)。

## 上传机制：秒传 / 分片 / 断点续传

客户端（Web 与桌面端统一）按「**秒传 → 分片续传 → 整文件**」三级通道上传（覆盖上传保持整文件通道）：

### 1. 跨用户秒传（v1.2.0）

- 上传前以 **MD5 + 文件大小** 双因子查询全局指纹库（`file_blob` 表），任意用户（或部门）传过同一内容即命中，**零上传流量**直接建立文件引用，任务状态显示「秒传」。
- 物理文件全服务器仅落盘一份（`storage/blobs/<hash前2位>/<hash>`），按引用计数管理：最后一个引用删除后物理文件才回收。
- 各用户/部门仍按逻辑占用各自配额——秒传省的是带宽与物理磁盘，不省逻辑配额。
- 并发安全：两人同时上传同一文件时由数据库唯一约束 + 原子引用计数保证只落一份。
- 对应接口：`POST /api/file/instant`。

### 2. 分片上传与断点续传（v1.2.0）

适用条件：文件 **大于 20MB** 自动启用。

| 参数 | 值 |
|------|-----|
| 分片大小 | 固定 5MB |
| 并发 | 3 |
| 单片失败重试 | 3 次 |
| 会话有效期 | 24 小时 |
| 校验 | 单片 MD5 + 末片余数大小 + 合并后整文件 MD5，任一环不符即拒绝并标记会话失效 |

- **断点续传**：上传中断（网络抖动、客户端退出）后重新上传同一文件，服务端按「同用户 + 同内容 + 同目标」恢复会话（`POST /api/file/chunk/init` 幂等），仅补传缺失分片；也可用 `GET /api/file/chunk/status` 查询已收分片。
- 会话可主动取消：`POST /api/file/chunk/abort` 清理暂存。
- 每 10 分钟定时任务清理过期会话、残留临时分片与孤儿暂存目录。
- 分片为普通 5MB multipart 请求，nginx 反代无需特殊配置（镜像已设 `client_max_body_size 2g`）。

### 3. 完整性保障

秒传与分片上传都以 MD5 为准；整文件上传若提供了 `file_hash` 也会做指纹校验（失败返回 `3205`「文件指纹校验失败，上传可能损坏」）。

## 下载与 Range 续传

- 下载接口 `GET /api/file/download?id=` 支持标准 HTTP `Range` 请求，命中时返回 `206 Partial Content`。
- 桌面客户端下载中断后从本地 `.zhy.part` 临时文件断点追加，并以 `.zhy.meta` 记录上下文防止不同文件的临时文件串用；完成后校验大小与 MD5。
- 每次下载（无 Range 头）会记录下载日志（用户、IP、User-Agent），供审计与流量统计。

## 分享管理

「我的分享」页（`/shares`）管理自己创建的外链分享：

| 项目 | 规则 |
|------|------|
| 分享对象 | 仅本人名下的**文件**（文件夹不支持分享/下载） |
| 分享码 | 系统生成唯一 9 位 token，链接形如 `/share/<code>` |
| 访问密码 | 可选，1–32 位（超长返回 `4112`），以 bcrypt 哈希存储 |
| 有效期 | 仅允许 `永久(0) / 1 天 / 7 天 / 30 天`（其他值返回 `4109`） |
| 密码校验 | 加密分享先经 `POST /api/share/verify-password` 换取访问令牌，凭令牌匿名下载；连续错误会被限流（`4106`「尝试过于频繁」） |
| 状态 | `active` / `expired`（到期惰性置为过期） / `cancelled`（手动取消） |
| 统计 | 浏览计数 +1（`GET /api/share/info`）；下载写 `download_log` |
| 清理 | 每 10 分钟定时任务把到期分享置为 `expired` |

分享下载同样支持 Range 206 与物理文件丢失检测（`4107` 文件已删除 / HTTP 410）。

## 回收站

> v1.3.0 起删除文件默认为**软删除**，可在「文件」页工具栏的**回收站**入口管理。

| 项目 | 规则 |
|------|------|
| 作用域 | 个人盘回收站与部门盘回收站**相互独立** |
| 保留期 | 默认 **30 天**（`trash_retention_days`，可设 1–365），到期由每小时定时任务彻底清除 |
| 操作 | **按原位置还原**（同名冲突自动改名，同名文件过多无法还原返回 `3521`）、单条**彻底删除**、**清空回收站** |
| 记录 | 记录删除人、原位置与到期时间 |
| 开关 | 「系统管理 → 系统设置」中独立开关（默认开启）；**关闭后新删除走硬删除，但不清毁回收站存量**，重新开启即可看到历史数据 |
| 配额 | 回收站内文件仍占用配额；彻底删除后释放 |

## 文件历史版本

> v1.3.0 起文件被**覆盖上传**时自动保留旧版本。文件行「历史版本」入口打开版本对话框。

| 项目 | 规则 |
|------|------|
| 保留策略 | 默认每文件 **10 个版本 / 30 天**（`version_max_count` 1–100、`version_retention_days` 1–365，可调） |
| 版本内容 | 修改人、大小、哈希、保存时间 |
| 操作 | **下载任意旧版本**（文件名自动带时间戳）、**一键恢复**（恢复动作自身再生成一个版本，可来回切换） |
| 磁盘占用 | 物理文件沿用内容寻址 blob：每多一个版本多一份引用计数，版本清理/彻底删除后引用归零才回收磁盘 |
| 开关 | 独立开关（默认开启）；关闭后不产生新版本，**存量版本仍可查看 / 下载 / 恢复** |

## 容量配额说明

| 项目 | 规则 |
|------|------|
| 默认配额 | `ZHY_DEFAULT_QUOTA`（默认 5 GiB = 5368709120 字节），仅影响之后新建的用户 |
| 调整入口 | 管理员在「系统管理 → 用户管理」中按用户调整（必须为正整数字节，且不能低于该用户已用空间，`1205`） |
| 扣减方式 | 上传/保存按**原子扣减**（SQL 条件更新），并发超额只有一个成功（`3106` HTTP 413） |
| 与秒传关系 | 秒传命中仍占用逻辑配额；物理磁盘全局去重 |
| 与回收站/版本关系 | 回收站条目与历史版本都按引用占用配额，彻底删除/版本清理后释放 |

## 文件类型限制

以下后缀禁止上传/保存（配置 `DENIED_EXTENSIONS`），返回 `3105`：

```text
exe bat cmd com scr msi vbs ps1 sh bash py pyc pyo jar app dll so php jsp asp aspx js vb wsf
```

单文件大小上限默认 **2 GiB**（`ZHY_MAX_UPLOAD_SIZE`），超限返回 HTTP 413、业务码 `4130` 或 `3202`。

## 在线预览与下载日志

- **在线预览**：文件预览由插件按后缀匹配提供（内置图片/视频/文档预览），预览走 `GET /api/plugin/file/stream` 内联流，支持拖动 seek（视频）；带 `Range` 的流式拖动**不重复记录下载日志**，避免刷日志。
- **下载日志**：本人下载、分享下载、插件流读取均写 `download_log`（用户、文件、分享 ID、IP、User-Agent），供管理端审计与流量统计（今日/近 7 天上/下行曲线）。

## 个人盘常见错误对照

| 提示 | 业务码 | 处理 |
|------|--------|------|
| 同级目录下已存在同名文件或文件夹 | `3103` | 改名或选择覆盖（覆盖自动进历史版本） |
| 存储空间不足，上传被拒绝 | `3106`（HTTP 413） | 清理回收站/旧版本或让管理员提升配额 |
| 禁止上传 .xxx 类型的文件 | `3105` | 压缩后上传或改用其他格式 |
| 文件指纹校验失败，上传可能损坏 | `3205` | 重新上传；持续出现检查网络/磁盘 |
| 文件夹暂不支持打包下载 | `3203` | 逐个下载或用桌面客户端同步整目录 |
| 上传会话不存在或已过期 | `3207` | 会话超 24h，重新发起上传 |
| 原位置已存在，无法还原 | `3521` | 回收站还原遇同名冲突，系统已自动改名；同名文件过多时手动处理 |
